# Электронный дневник (diary-project)

Система учёта успеваемости, домашних заданий и уведомлений в школе.

## Стек
- Python 3.10+
- Flask 3.0
- SQLite

## Установка
```bash
python -m venv .venv
source .venv/bin/activate  # Linux/macOS
# .venv\Scripts\activate   # Windows
pip install -r requirements.txt
